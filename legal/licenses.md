Assets and third-party review · 2026-10-19.1

Illusion's orbital/checkerboard UI and icons are original code-generated artwork. No copied Sol's RNG art, game logo, music or official endorsement is included. The inspiration/name reference is not a trademark clearance; the operator must review naming/branding before public launch. User uploads must be owned or licensed by the uploader.

Fonts are family-name references to fonts already licensed/installed on each device, with system fallbacks. No font binaries are redistributed. Windows/.NET, Node.js and browser Web Crypto/IndexedDB are platform dependencies. The Windows app and Mini App load no npm runtime packages, third-party JavaScript SDKs, analytics, remote fonts, stock-image feeds or advertising scripts. The hosted relay uses Cloudflare Workers/Durable Objects and platform compatibility code bundled by Wrangler; Wrangler/Miniflare are build and test dependencies. Telegram Bot API, Cloudflare hosting and optional Cloudflare tunneling are external services, documented in Privacy. The official cloudflared binary is checksum-verified and is not bundled in the app download. Its Apache-2.0 license is at https://github.com/cloudflare/cloudflared/blob/master/LICENSE. The test-only FFmpeg fixture is an original blue rectangle and silence. A dependency inventory is maintained in compliance/REVIEW.md.
