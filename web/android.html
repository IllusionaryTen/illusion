Illusion on Android

Open the messenger inside Telegram, or install it on your home screen from your browser. The Android version uses the same Illusion account and hosted chats.

This is a web install, so there is no APK file to sideload. It needs an internet connection to send and receive messages.

Open Illusion

Install on your home screen

  1. Open Illusion in Chrome using the button above.
  2. In Chrome, open the menu and choose Install app or Add to Home screen.
  3. Confirm. Illusion will appear alongside your other apps.

To use it inside Telegram instead, return to the bot and tap Open Illusion. Never install APK files from untrusted senders.
